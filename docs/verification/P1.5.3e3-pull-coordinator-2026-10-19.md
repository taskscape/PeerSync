# Ordered pull coordinator

The host-owned Puller now runs bounded passes and a cancellable background loop.
Startup recovers pending operations before scanning and rebuilding legacy needed
metadata. An unbound index with recovery state fails closed. Later scans provide
changed paths for incremental needed recomputation. Puller and RescanScheduler
share one process-wide scan budget. Preserved/changed-target scans are coalesced
at batch end, outside mutation gates. Ordinary failures persist exact-work retry
state and recover staged intents before independent work continues; unavailable
recovery stops that pass. Folder failures use bounded backoff without holding
gates, and notifications cannot bypass that folder retry delay.

Scheduled queries filter incomplete cached deletion ranges before LIMIT, retain
local-source metadata work and compute the next eligible durable deadline. The
applier still verifies actual selection and range state. The loop wakes for
index/local notifications, durable retries or periodic scans, and exposes bounded
count-only outcomes. No transport or keys are owned/disposed by the coordinator.
Host watchers request scans explicitly; production service wiring remains P2/P3.

Fifteen real-engine/native coordinator cases cover ordered parent creation,
size-priority files and child-before-parent deletion; locked target/restart
backoff with independent progress; bad chunks/new versions and diagnostic
privacy; prepared recovery before scan; ten public copies in one rescan;
incomplete sender ranges; cancellation/recovery; hosted wake/restart and idle
gate release; shared scan budget cancellation; timer-driven durable retries and
periodic scans; missing-root retry; unbound journal preservation; an unknown
child after startup; and changed-user-target preservation through the next
application. Two additional Storage cases place eligible entries behind 1,000
waiting deletions and verify deadline, root and range filtering. All 17 PullWork
Storage cases pass. Deterministic timer tests exercise the real background loop.

Canonical `build/Verify.ps1 -SkipFuzz` passes all 882 tests (126 Core, 15 Crypto,
five Protocol, 553 Engine, 183 Storage), native probes, diagnostic/watcher/QUIC
checks and publication in 108.1905791 seconds, exit 0. Separate 600-second CI
fuzz is explicitly skipped locally. Scoped compiler/analyzer checks for Engine,
Storage, both test projects and QuicBasics are clean, with no truncation or load
warnings. Logs: `artifacts/p1-puller-{build,tests,verification}.log`; native TRX:
`artifacts/tests/puller/`.
