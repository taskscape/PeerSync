# Protected directory metadata recovery checkpoint

Schema 32 retains up to 4096 exact root-bound source envelopes independently of
their former local rows. Needed/index updates admit sources atomically; capacity
rolls back the enclosing remote page. Durable run ordinals, byte/source bounds,
retry deadlines, paged route cursors and bounded expiry survive restart. Retained
RO directory originals are recovered from the case ledger, with no signing or
native mutation authority added.

The coordinator fetches authenticated graph metadata without holding the
reference gate. Each source has a ten-second attempt and each candidate a
one-second deadline. Two preferred hints and six paged known devices provide
bounded fallback, including forwarders beyond the first page. Cached nodes are
registered as owned before graph progress even when the previous process stopped
between writing their cache files and flushing ownership. Logical apply requests
preview snapshot reconciliation. Incomplete required graphs still withhold GC.
