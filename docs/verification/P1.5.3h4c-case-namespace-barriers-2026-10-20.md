# Case namespace and directory-publication barriers

Pending sources now block ordinary incoming mutation inside the original source
and reserved copy namespaces, including descendants and destructive ancestor
transitions. The shared exact indexed ancestor/range query is used by selection,
late/recovery guards and FULL ordinary apply commit. Existing missing live
ancestor-directory creation remains allowed when only descendant work is
pending; it cannot bypass a source/copy-root ancestor barrier. Owned case workers
and explicit restore retain their separate paths.

An unfinished directory copy also holds directory advertisements at, above or
below its reserved destination. The hold is bound to the accounted root native
ID and its member cursor; missing root/cursor coverage stays incomplete. Legacy
scanner directory publication waits, snapshot staging pauses/retains templates,
the publication worker defers, and both FULL snapshot completion primitives
recheck coverage. Previous signed rows and capture/queue records remain intact.
File scanning can still publish independently. Exhausting member installation
releases publication holding only; ordinary incoming mutation remains blocked
until whole-source completion proof succeeds.

  cover original/copy descendants, namespace release boundaries, exact literal
  `%`/`_` and deep ancestry, the missing-ancestor allowance, and FULL apply
