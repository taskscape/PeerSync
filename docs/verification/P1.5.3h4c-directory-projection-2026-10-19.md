# Authenticated subtree projection checkpoint

P1.5.3h4c remains WIP. The new bounded projection reader is metadata only;
it creates no directory/file, assigns no native ownership and completes no
case-preservation obligation. Production scanner activation, native subtree
journals/recovery, received-root integration and the five connected directory
case baselines remain open.

The reader binds the original signed directory source ID, snapshot hash/length,
complete non-retiring graph, pinned physical root and indexed root identity.
It touches validated graph use, pages the graph's canonical member index and
reopens each exact record/blob envelope, signature and canonical parent/key.
Members retain their original signed bytes; relative segments map into the
source-derived case-conflict root, preserving older signed parent-case aliases.
Destination path validation precedes returning a page. Cursor/page results
never establish native completion or authority to skip earlier copy work.

Passes are bounded to 1000 members and an 8 MiB envelope budget, allowing one
bounded oversized envelope. The next record-node header is checked before
loading its envelope fragments. Fetched metadata is flushed before returning
and during cancellation/error cleanup. Diagnostics use fixed stages/types,
counts/bytes and native error numbers without paths or signed payloads.

All 254 Storage cases pass locally (6.36 seconds, exit 0). The added member-page
case persists 1001 members, reopens the database, reads 1000 then one by exact
cursor, checks graph isolation/bounds, and confirms indexed seek without a
temporary sorting tree.

All 63 focused native Engine cases pass locally (10.22 seconds, exit 0),
including 13 projection cases: nested original signatures/causal parent aliases,
one-member and one-envelope continuation, missing/incomplete/retiring/root-
mismatched graphs, substituted member keys/node kinds, exact old-source use
after live replacement, cancellation, empty graphs, and fetch/flush budgeting.
The fetch fixtures remove only verified exact cache bytes owned by their test
root. They then require actual fetching, show that the next blob is not read
past budget, and verify durable retained metadata after successful return or
cancellation. Projection leaves user files and conflict destinations untouched.

Scoped compiler/configured-analyzer diagnostics are clean in Engine, Storage
and both test projects, without load warnings or truncation. The latest broader
Engine checkpoint remains the 831-case run documented in the scanner report:
826 pass and the five retained subtree failures. These later focused additions
are not a claim that the complete final suite or native subtree recovery passes.
No canonical run, additional GitHub CI run or feature PR was started here.
