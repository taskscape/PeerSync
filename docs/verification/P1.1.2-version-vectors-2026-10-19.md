# P1.1.2 version vectors — 2026-10-19

Core implements componentwise comparison, maximum merge and checked increment.
Missing counters are zero. Canonical outputs omit zero entries, preserve
inputs and fail if increment would wrap `ulong.MaxValue`.

The compact storage representation is a minimal unsigned LEB128 entry count,
then ascending unsigned fixed64 little-endian device IDs and minimal LEB128
positive counters. It is separate from the Protobuf `VvEntry` wire list.
The decoder checks count against available input before allocating and rejects
duplicate/unsorted IDs, zero counters, truncation, overflow, nonminimal varints
and trailing bytes. Empty vectors encode as the single byte `00`.

- Fixed unsigned device-order/varint vector, empty and zero entries, maximum
