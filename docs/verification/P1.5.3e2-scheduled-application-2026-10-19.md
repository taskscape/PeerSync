# Guarded scheduled application

File and directory appliers now offer scheduled entry points while retaining
existing direct-call signatures. A scheduled tombstone waits for a declared,
fully received winner-source index range. Under the filesystem gate it acquires
the reference gate, reselects current authenticated work and checks the range.
It retains that gate through bounded deletion/archival and metadata commit.
A winner that becomes live while waiting releases references before fetching.
Live downloads continue to permit index receipt. Announcements use a NeededSet
entry point sharing the reference gate with receive; transport authentication
remains the caller's P2 responsibility. Local-source metadata merges need no
remote range announcement.

Fetch receives the source chosen inside the applier, followed by chunk hash and
length. Scheduled file results request a scan when public versions are preserved
or a changed target is deferred. Directory results retain their existing scan
requirement for nonempty/changed data. The coordinator must scan outside mutation
gates and recover pending intents before scanning after any failure/restart.

Ten added native cases verify missing/incomplete/complete index barriers,
reference exclusion through file moves and directory deletion, empty/nonempty
directory preservation, actual-source routing with concurrent index receipt,
reselection to a live winner after waiting, public conflict/changed-target scan
requirements and cancellation releasing gates without reserving an intent.
Existing privacy coverage now includes pending/complete/failed range diagnostics.
Logs contain correlated events, counts and error codes without paths or payloads.

Canonical `build/Verify.ps1 -SkipFuzz` passes 865 tests (126 Core, 15 Crypto,
five Protocol, 538 Engine, 181 Storage), native/probe/diagnostic/watcher/QUIC and
publication checks in 118.3845759 seconds, exit 0. Separate CI fuzz is explicitly
skipped locally. Scoped Engine and Engine.Tests compiler/analyzer checks are
clean, with no truncation or workspace load warnings. Full log:
`artifacts/p1-scheduled-apply-verification.log`; prior whole-Engine focused run
passed all 537 then-current cases before cancellation/privacy additions.

This is local evidence pending the batched coordinator PR and main/CI evidence.

production simulation requirements remain open.
