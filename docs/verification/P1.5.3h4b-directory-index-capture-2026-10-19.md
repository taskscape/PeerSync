# Trusted indexed directory capture

Schema 26 introduces a dedicated mutation epoch. SQLite triggers advance it on
every local-row insert/update/delete, including readiness and cache changes
that leave the advertised local sequence unchanged. Overflow aborts the whole
mutation rather than wrapping. A FULL conditional bind attaches a revalidated
input manifest to an exact epoch; progress and publication compare that witness.
Generic enumerable capture clears it and keeps its two-pass verification.

The Engine's indexed capture mode pins the root/native directory and uses the
checked epoch to continue strictly after its saved child cursor. A changed
witness revalidates the full manifest, retaining its accepted prefix when the
identity is unchanged. Batches authenticate and validate local-row binding,
counts, ordering and end-of-input before durable progress. This avoids a full
input revalidation per unchanged 1000-member advancement. It does not yet
replace the scanner/coordinator's full-scan scheduling.

Integration also corrects the earlier child projection: signed but locally
unready files retain authenticated membership. Readiness is availability, not
a signed deletion. Capturing metadata does not set readiness or claim bytes
are available; copying still verifies chunks. The earlier children checkpoint's
unready-row exclusion is superseded by this tested correction.

All 240 Storage cases pass (4.98 seconds, exit 0), including epoch/readiness/
deletion changes without advertised sequence changes, conditional progress and
publication rejection, generic witness clearing and atomic overflow rollback.
All 166 affected native Engine cases pass (8.19 seconds, exit 0), including
27 capture/publication cases. Restart continuation emits only one full-input
revalidation for unchanged inputs and produces the exact uninterrupted root;
identical-manifest epoch changes preserve the prefix, new children restart it,
and readiness repair keeps signed membership without setting readiness. Races
before witness binding/progress and corrupted member counts retain safe state.
Legacy downgrade/upgrade fixtures and backup assertions are updated to 26.
All four changed projects have zero warning/error compiler/configured-analyzer
diagnostics, with no load warnings or truncation. Capture-state impact analysis
returned one contract, fifteen production references, four test references and
nine dependent projects, without truncation.
