registration does not transfer engine ownership. An empty host explicitly
reports production sync unavailable. The service entry point hosts this status
slice; installed configuration and production sync supervision remain P2 work.

sequence fields. Messages are capped at 256 KiB, rows at 1,000 and active

and concurrent disposal shares shutdown completion. Diagnostics record bounded
counts, outcomes and exception types without paths, keys or caller identities.
