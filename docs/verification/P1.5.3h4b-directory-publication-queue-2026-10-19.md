capture, current input epoch, native/root identity and prior local sequence.

source ID, input manifest and child-key fingerprint, and releases both pending
records atomically. Pending direct child queues prevent completion. The Engine
retains native handles and authenticates the staged metadata/root; readonly
reconstruction can only retain an identical current authenticated root.
