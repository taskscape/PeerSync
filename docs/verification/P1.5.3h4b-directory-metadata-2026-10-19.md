Task P1.5.3h4b remains WIP. This checkpoint supplies bounded authenticated
metadata I/O, not subtree capture, complete graph reference coverage or native
directory materialization.

`DirectorySnapshotBlocks` stores exact signed envelopes as bounded Blob and
Record nodes through independently owned `PublishedBlocks`. It flushes FULL
ownership accounting every 128 captured nodes and exposes an explicit final
flush required before publication. Reads verify exact lengths and BLAKE3 before
caching, freeze provider buffers, authenticate original envelopes with folder
keys, and check supported live types and canonical immediate-parent membership.

means an empty directory. Local sequence is deliberately absent from envelopes.

when it encounters a snapshot-bearing directory. It cannot activate an
incomplete snapshot or let retention sweep using the previous active one.
