# P1.5.3h3a file-case gossip and lifecycle (local)

A new native gossip regression reproduces three visible files when a ready
authenticated case copy arrives before local preservation: the existing copy
was treated as a collision. It now passes with two visible payloads. Reuse
requires a matching ready signed local publication, current sequence/native
identity and guarded whole-file bytes. FULL observation grants no native
deletion ownership. Unknown/unsigned occupants still allocate another slot.

Per-root/source FULL retries persist attempts, failure time and 10–600 second
deadlines. Backwards time makes old work due and resets its delay. Installed
accounting clears retries. Due queries visit at most 1,000 pending sources;
unavailable content and unsupported subtrees defer while independent case and
normal work progress. Coordinator deadlines include case-only work. A hosted
timer test with no ordinary needed rows verifies the actual ten-second wake.

Cancellation before preparation or after the native move leaves recovery
proof and pending sources. Recovery restores signed hidden/read-only attributes
before publication. A new reparse collision regression initially stranded the
original path; unclassifiable/reparse occupants now count as occupied and a
different no-overwrite slot is used. The link and outside bytes stay untouched.

Completed sources record completion time. After 24 hours, FULL metadata-only
compaction removes large source envelopes/forwarder fields in bounded batches,
retaining root/path/portable-ID completed witnesses. Pending, foreign-root and
future-completed records are preserved. Replayed authenticated sources cannot
be re-admitted through a compact witness. No filesystem deletion follows from
these observation/compaction records. Production coordinator compaction visits
at most 64 records per pass; the storage API is bounded at 1,000.

All 30 focused connected/native cases and nine storage-ledger cases pass.
Two initial storage assertions were corrected to query after the second failure
time and expect the established foreign-root exception; runtime checks stayed
strict. Final canonical `build/Verify.ps1 -SkipFuzz` passes 1,125 cases (134 Core,
15 Crypto, seven Protocol, nine Net, 715 Engine, 214 Storage, 28 Control.Contracts,
three Simulation), plus native/probe/watcher/QUIC/publication checks in
120.1103386 seconds, terminal exit 0. The simulation property method runs eight
flat-path scenarios; method totals are not seed counts. Boundary fuzz was
explicitly skipped locally. Scoped Engine/Storage and both test projects have
clean configured Roslyn diagnostics without truncation/load warnings.
