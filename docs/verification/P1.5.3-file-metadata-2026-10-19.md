# P1.5.3 handle-based metadata preparation — 2026-10-19

`FileMetadata` prepares a sibling temporary file through held handles. Copy the
original's DACL, including inheritance protection, into a fresh `FileSecurity`
object whose access section is marked modified, then persist it to the new
handle and copy creation time. Owner/group/audit sections are not synchronized.
A genuinely new sibling inherits its parent DACL through exclusive creation.
Borrowed non-owning `SafeFileHandle`/stream wrappers hold an explicit reference
while the ACL API runs; disposing them leaves the caller's mutation guards open.

Validate remote UTC ticks before destructive changes. Dates before FILETIME's
1601 epoch, invalid .NET ticks and the exact zero FILETIME sentinel fail rather
than silently retaining the wrong mtime. Set times before read-only/hidden
attributes; other remote attribute bits are masked. The old file's read-only
flag can be cleared through its guard, the exact handle archived without
overwriting, then its original attributes restored.

Four added native tests cover exact protected-DACL/creation-time preservation,
continued guard ownership, new-file inherited permissions, exact UTC mtime and
attribute masking, read-only guard/clear/archive/restore with unchanged bytes,
and invalid timestamps leaving metadata unchanged. All 96 Engine cases pass;
scoped Engine/Engine.Tests compiler and analyzer checks are clean, with no load
warnings or truncation. The canonical local runner passed all 264 cases, native
probes, diagnostics, watcher recovery and probe publishing in 176.95 seconds,
exit 0, with fuzz explicitly skipped. Required CI remains pending.
Evidence: `artifacts/p1-metadata-tests.log`,
`artifacts/p1-metadata-verification.log`.

This is preparation support, not a replacement transaction. P1.5.3 remains WIP;
the coordinator must validate before moving anything, preserve losing bytes,
flush file contents, persist/recover apply intent and commit/recompute index
state. Archive accounting, pruning and target-lock backoff remain pending.
