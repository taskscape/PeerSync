# Indexed logical directory children

Schema 25 maintains canonical parent and UTF-16BE ordinal sort keys atomically
with local row writes. Startup backfills legacy sort keys in FULL 1000-row
batches before returning the index; an indexed NULL-only work set resumes
after interruption without rescanning already completed rows. Publication
bytes, vectors and local sequences remain unchanged by this metadata backfill.

Logical child reads use the parent/sort index, strict after-key continuation,
at most 1000 rows and an 8 MiB record/vector byte budget. A single larger
bounded record is allowed; the next body is not materialized merely to decide
to defer it. `More` explicitly handles byte-limited short batches. Ignored,
unsupported, deleted, unsigned and unready file rows are excluded; a ready
NeedsRescan row can retain its exact last published version. Engine callers
must still authenticate envelopes and validate local-row binding.

legacy migration, and a failed 1001st backfill update followed by restart.
Exactly 1000 prior backfill updates remain committed; all publication sequences
are unchanged. Query plans use both intended indexes without a temporary sort.
