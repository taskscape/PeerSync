# Durable pull work, sender ranges and retries

Migration 19 adds scheduling descriptors to needed rows, monotonic sender index
targets and root/exact-work retry state. Authenticated selection computes the
descriptor in the existing remote/cursor/needed transaction. Descriptors own
their fingerprint buffers and include desired signed bytes, chosen source and
current native/local publication identity. Legacy rows stay unscheduled until
recomputed. The applier must revalidate the signed decision before mutation.

Queries return at most 1,000 descriptors: directories before live files, then
file deletions and deepest-first directory deletions. Per-path priority precedes
folder size/mtime preference. Persistent retry delays are 10, 20, 40, 80, 160,
320, 600 seconds, capped at 600. Only exact current work can record a failure
or clear its retry; new work and removed needed rows invalidate stale retries.
Clock rollback makes old delays eligible and resets the next delay; maximum
ticks saturate without overflow. Sender targets never decrease in a generation;
only contiguous received cursor updates complete them. Generation reset is P2.

Fifteen Storage cases cover all priorities, bounds, restart/backoff, stale
failure/completion, cancellation rollback of descriptors plus retry invalidation,
actual SQLite failures, root binding, frozen queued buffers, monotonic ranges,
cursor gaps and v18 backup/legacy migration. Six Engine additions cover the four
authenticated stage kinds, stable/new remote/native fingerprints and an actual
SQL failure rolling back descriptors, records and cursor. All 20 NeededSet
cases pass. Scoped compiler/analyzer checks for Storage, NeededSet and affected
tests are clean, without truncation or workspace load warnings.

Canonical `build/Verify.ps1 -SkipFuzz` passes all 855 tests (126 Core, 15 Crypto,
five Protocol, 528 Engine, 181 Storage), native/probe/diagnostic/watcher/QUIC and
publication checks in 104.9515709 seconds, exit 0. Separate CI fuzz is explicitly
skipped locally. Evidence: `artifacts/p1-pull-{work,needed}*` and
`artifacts/tests/pull-{work,needed}/`.
