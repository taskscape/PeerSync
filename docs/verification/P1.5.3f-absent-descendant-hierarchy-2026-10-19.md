# P1.5.3f absent-descendant hierarchy integration (local)

Two connected-engine regressions reproduced permanently needed file tombstones
on fresh nodes: the former parent had disappeared or was now a file. The
applier tried to open a directory parent and failed each retry, despite there
being no descendant object to delete. Baseline evidence:
`artifacts/p1-hierarchy-baseline.log`, `artifacts/tests/hierarchy-baseline/`.

The new rooted directory probe retains ordinary ancestor handles and classifies
only missing components/ordinary files as absence. Reparse, access and sharing
errors remain failures. An ancestor file cannot be removed/replaced while the
probe is held. Normal existing-directory opening retains the previous path.
No component is created by probing.

For absent parents, file and directory tombstones reserve a prepared FULL
intent and durably complete metadata without native deletion. Scheduled range
guards remain held. Recovery re-probes and retains the same range barrier;
new descendants that appear before recovery use ordinary changed-target
preservation. Retained originals still require existing identity/hash/accounting
proofs. Known live metadata first defers to a scan so immutable supersession
archiving preserves its published bytes. Metadata-only completion requests a
fresh scan to observe concurrent creation without deleting the new data.

Eleven additions cover connected nested file/directory tombstones under missing
or file parents, interrupted prepared intents, new descendants during recovery,
new incomplete sender targets, known-live version archival and native probe
ownership/sharing. Existing reparse tests also exercise the new probe. After
the first nine additions, 103 focused native/applier/transport cases passed;
the final connected variants are included in the full runner.

Canonical `build/Verify.ps1 -SkipFuzz` passes 981 cases (129 Core, 15 Crypto,
seven Protocol, nine Net, 631 Engine, 187 Storage, three Simulation), native/
probe/diagnostic/watcher/QUIC and publication checks in 140.2467289 seconds,
exit 0. The property method runs eight generated flat-path scenarios. Separate
required boundary fuzz was explicitly skipped locally. Scoped Engine and
Engine.Tests compiler/analyzer checks are clean without truncation/load warnings.
Roslyn impact checks for SafeFileTree/FileApplier/DirectoryApplier were expanded
to cover all 50/4/3 production references and 59/66/4 test references; final
sections are untruncated, with four dependent projects and no load warnings.
