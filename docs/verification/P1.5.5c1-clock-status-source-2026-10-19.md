# P1.5.5c1 typed clock-status source (local)

Two endpoint-offset regressions fail before repair: an incoming handler rejects
the caller's skewed Hello before returning its own sample, so the caller sees
the remote endpoint's oppositely signed offset. A valid identity/protocol/nonce
Hello now exchanges UTC samples without requiring clock admission first. Each
endpoint evaluates its own peer-minus-local offset. Index and block requests
retain the existing admission gates; the two new baseline cases and connected
checks verify that no index rows are exchanged while skewed.

`PeerSessionClockStatus` freezes authenticated device identity, local session
correlation, clock reason/offset and connection state. `PeerClockStatusPage`
freezes unique session rows and explicitly signals truncation. Neither is an
admission token; string representations redact identities.

PeerIndexSession now preserves the last skew/invalid display reason separately
from disconnected admission. Reset still immediately invalidates queued work
and the public admission status becomes AwaitingHello. Fresh Hello can restore
fresh work; old-generation guards remain unchanged. The display/lifecycle lock
does not surround database callbacks or change those pure admission checks.

TransportFolder tracks its host-owned incoming/outgoing sessions. The bounded
ledger retains the latest closed result for at most 64 peers, rejects older
late-close replacement, suppresses closed warnings when a fresh observed
session exists and returns at most 1,000 rows with explicit truncation. Status
polling evaluates live guards, so local clock jumps/recovery appear without
requiring index traffic. Disposal removes sessions from active tracking;
closed history is display-only. The host still owns/drains transports and
folder work under the existing lifetime contract.

Five Core additions cover frozen identities/pages, privacy and malformed
state/identity/duplicate/bound inputs. Fifteen Engine additions cover both
offset signs, both endpoint histories, reconnect clearing, missing Hello,
invalid timestamp/elapsed samples, forged identity/nonce/protocol, blocked
index/block access, polling after a local jump, history/page bounds, late close,
snapshot immutability and disconnected display versus admission. All 53
focused Engine and five new Core cases pass. Initial fixture compiler/analyzer
issues were corrected by awaiting ValueTasks and keeping Span values out of
assertion expression trees.

Canonical `build/Verify.ps1 -SkipFuzz` passes 1,049 cases (134 Core, 15 Crypto,
seven Protocol, nine Net, 676 Engine, 205 Storage, three Simulation) plus
diagnostic/native/probe/watcher/QUIC and publication checks in 113.8819124
seconds, exit 0. The property method runs eight flat-path scenarios, not 1,049
simulation seeds. Required boundary fuzz was explicitly skipped locally.
Scoped Core/Core.Tests/Engine/Engine.Tests compiler/configured analyzer checks
are clean without truncation or workspace-load warnings. Impact sections for
PeerIndexSession/TransportFolder/PeerFolderConnection are untruncated and cover
all four dependent projects.
