Bugs and feature requests

Open an issue on GitHub so others can find the answer too. Include your Windows build, the PeerSync version and what you expected to happen.

Open a GitHub issue

Attach a sanitized bundle

For anything that misbehaved, run this on each PC shortly after the problem and attach the ZIP. It contains structured events and timings, and leaves out keys, paths, file contents and network addresses.

psp diagnostics --output bundle.zip

Never attach settings files, certificate private keys or the raw service database.

Security disclosures

Found something that weakens the key chain, the transport or the service's permissions? Pick "Security question or disclosure" in the form and keep details out of public issues until we have replied.
